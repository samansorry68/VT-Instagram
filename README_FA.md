# V.T Instagram — نسخه اولیه قابل اجرا

## امکانات
- گرفتن لینک پست یا ریلز عمومی
- تلاش برای دریافت کامنت‌ها از طریق Instaloader
- جست‌وجو و فیلتر نتایج
- کپی کامنت‌ها
- خروجی XLSX و CSV

## اجرا روی کامپیوتر یا سرور
Python 3.10 یا جدیدتر لازم است.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

سپس در مرورگر باز کنید: `http://127.0.0.1:8080`

## استقرار روی سرویس میزبانی Python
کل پوشه را در یک مخزن Git قرار دهید و روی یک سرویس میزبانی که Python web services پشتیبانی می‌کند deploy کنید. دستور start:
`gunicorn app:app`

## نکته مهم درباره اینستاگرام
این پروژه اتصال آزمایشی واقعی دارد، اما دریافت کامنت تضمین‌شده نیست. اینستاگرام می‌تواند درخواست‌های خودکار را محدود کند، ورود بخواهد یا ساختار دسترسی را تغییر دهد. API رسمی Meta برای دسترسی به کامنت‌ها نیازمند نوع حساب، مجوزها و دسترسی مناسب است و برای هر پست متعلق به دیگران دسترسی عمومیِ تضمین‌شده نمی‌دهد.

برای نشست ورود، هرگز رمز عبور را در این فرم یا داخل کد وارد نکنید. در صورت نیاز، فقط از روش رسمی و امن ساخت session در محیط مورداعتماد خودتان استفاده کنید؛ فایل session را عمومی نکنید یا در مخزن Git قرار ندهید.
